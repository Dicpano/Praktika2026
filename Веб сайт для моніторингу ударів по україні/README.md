# Моніторинг повітряних тривог України

Сайт: карта областей із реальним статусом повітряної тривоги (офіційний API
[alerts.in.ua](https://alerts.in.ua)), стрічка подій, статистика та агрегатор
реальних новин (RSS). Повне ТЗ — у [`TZ.md`](TZ.md).

**Чесно про дані:** тривоги (оголошено/відбій, тип: повітряна/артобстріл/
вуличні бої/хімічна/ядерна) — реальні, з офіційного API, за наявності
токена. Новини — реальні. Координат конкретних ударів (Шахед/ракета/КАБ)
тут немає — публічного офіційного API з такою деталізацією не існує (див.
вкладку «Про проєкт» у самому застосунку).

## Запуск

Потрібен лише Python 3 (без Node.js, без npm, без встановлення пакетів).

```
python server.py
```

Відкрити в браузері: http://127.0.0.1:8000

Без токена сайт запуститься і працюватиме (карта, новини, статистика), але
вкладка тривог покаже чесний стан "не налаштовано" замість вигаданих даних.

## Підключення реальних тривог (alerts.in.ua)

1. Заповнити форму запиту токена: https://alerts.in.ua/api-request
   (поле «Галузь використання» → **Other**, у описі вказати, що це
   навчальний студентський проєкт-монітор тривог). Токен приходить на email.
2. Скопіювати `config.example.json` → `config.local.json`.
3. Вставити токен у поле `alerts_api_token`.
4. Перезапустити `python server.py`.

Альтернатива без файлу — змінна середовища (має пріоритет над файлом):

```
# PowerShell
$env:ALERTS_API_TOKEN = "ваш_токен"
python server.py
```

`config.local.json` додано в `.gitignore` — токен не потрапить у git.

## Структура проєкту

```
index.html              головна сторінка (карта, статистика, новини, журнал, про проєкт)
css/style.css            стилі, темна тема
js/
  state.js               спільне сховище даних і довідники (реальні alert_type)
  alerts.js               полінг реальних тривог alerts.in.ua, синтез alert_start/alert_end
  map.js                  карта областей (Leaflet)
  feed.js                 стрічка подій + фільтри
  archive.js               журнал подій, пошук, експорт CSV
  stats.js                статистика й графіки (Chart.js)
  news.js                  агрегатор новин (реальні RSS через проксі)
  app.js                   ініціалізація, навігація, банер стану підключення
data/
  ukraine-oblasts.geojson   межі 27 регіонів України (geoBoundaries/OSM)
  rss-sources.json           перелік RSS-джерел новин
server.py                 Python-сервер: статика + проксі /api/rss і /api/alerts
config.example.json       шаблон конфіга токена (скопіювати в config.local.json)
TZ.md                     технічне завдання
```

## Джерела даних

- **Тривоги:** офіційний API [alerts.in.ua](https://api.alerts.in.ua/v1/alerts/active.json)
  (потрібен токен). Дає реальний статус тривоги по областях і тип
  (`air_raid`, `artillery_shelling`, `urban_fights`, `chemical`, `nuclear`).
  Архіву за минулі дні API не надає — статистика й журнал накопичуються
  з моменту запуску сервера.
- **Межі областей:** [geoBoundaries](https://www.geoboundaries.org) (ADM1, дані OpenStreetMap).
- **Новини:** публічні RSS-стрічки (BBC, Al Jazeera, The Guardian, Укрінформ,
  УНІАН, Українська правда, Gazeta.ua та обласні видання) — повний список у
  `data/rss-sources.json`.

## Обмеження (щоб не було ілюзій)

- Немає офіційного джерела з координатами конкретних ударів — тільки статус
  тривоги по областях.
- Немає історичного архіву тривог — тільки те, що накопичилось із моменту
  запуску вашого сервера.
- Це не заміна офіційного оповіщення (сирени, застосунок «Повітряна
  тривога», Telegram-канал Повітряних Сил ЗСУ, вказівки ДСНС).
