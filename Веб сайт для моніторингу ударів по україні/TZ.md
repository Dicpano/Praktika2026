# Технічне завдання

## Проєкт: Веб-сайт моніторингу повітряних тривог України

**Дата:** 2026-08-07 (оновлено: перехід на реальні дані тривог)
**Тип:** Навчальний проєкт (практична робота)

---

## 1. Мета проєкту

Створити веб-застосунок, що в єдиному інтерфейсі показує:
1. Реальний статус повітряної тривоги в розрізі областей України на карті;
2. Агреговану стрічку новин з глобальних, всеукраїнських та обласних медіа;
3. Статистику й аналітику по тривогах за період.

> **Важливо (безпека користувачів, чесність даних):** офіційного публічного API з координатами конкретних ударів (Шахед/ракета/КАБ) не існує — така інформація поширюється лише неофіційно (моніторингові Telegram-канали) без гарантії точності, тому в проєкті її свідомо немає. Натомість підключено **офіційний API alerts.in.ua** — реальний статус тривоги (оголошено/відбій) по областях і її тип. Проєкт не є і не замінює офіційні системи оповіщення (сирени, застосунок «Повітряна тривога», Telegram-канал Повітряних Сил ЗСУ, вказівки ДСНС) — дисклеймер з посиланнями постійно на сайті.

## 2. Аудиторія

Навчальна демонстрація; потенційно — основа для подальшого розвитку (дослідники, журналісти, аналітики).

## 3. Функціональні модулі

### 3.1. Карта областей («Дашборд»)
- Інтерактивна SVG-карта 27 регіонів України (24 області + АРК + м. Київ + м. Севастополь) на базі Leaflet, полігони з відкритого датасету geoBoundaries (OpenStreetMap).
- Кольорове кодування області за поточним реальним статусом тривоги (alerts.in.ua):
  - зелений — спокійно, тривоги немає;
  - жовтий — повітряна тривога (`air_raid`);
  - оранжевий — загроза артобстрілу / вуличні бої (`artillery_shelling`, `urban_fights`);
  - червоний — хімічна/ядерна загроза (`chemical`, `nuclear`) — вкрай рідкісний, гіпотетичний стан.
- Клік/тап на область → попап з назвою, поточним статусом і 5 останніми подіями по ній.
- Легенда кольорів, індикатор часу останнього оновлення, банер стану підключення (токен підключено / не підключено).

### 3.2. Стрічка подій (live feed)
- Хронологічна стрічка реальних подій (найновіші зверху): оголошення й відбій тривоги по областях, автооновлення опитуванням API кожні ~20 с.
- Кожна подія: час (реальний `started_at` з API), область, тип тривоги, короткий опис.
- Фільтри: за областю, за типом тривоги, за період (година/доба/тиждень).

### 3.3. Журнал/архів подій
- Таблиця подій, що накопичились із моменту запуску сервера (архіву за минулі дні API не надає), з сортуванням і пошуком.
- Експорт відфільтрованого набору в CSV.

### 3.4. Статистика
- Стат-плашки: тривог сьогодні, тривог за тиждень, областей у тривозі зараз, область, що найчастіше в тривозі.
- Стовпчикова діаграма: кількість тривог по областях (топ-10), з моменту запуску сервера.
- Часовий ряд: динаміка тривог за добу, з моменту запуску.
- Кільцева діаграма: розподіл за типом тривоги (повітряна / загроза артобстрілу / вуличні бої / інше — хімічна й ядерна згорнуті в «Інше» через їхню рідкісність і обмеження безпечної категорійної палітри на 3 слоти для all-pairs форм).

### 3.5. Агрегатор новин
- Підбірка новин з RSS-стрічок трьох рівнів:
  - **Глобальні:** BBC News World, Al Jazeera, The Guardian World;
  - **Всеукраїнські:** Укрінформ, УНІАН, Українська правда, Gazeta.ua;
  - **Обласні:** 057.ua (Харківська обл.), Думська (Одеська обл.), 056.ua (Дніпропетровська обл.), 0642.ua (Запорізька обл.), 032.ua (Івано-Франківська обл.).
- Фільтр за рівнем джерела та за областю.
- Кожна новина — заголовок, джерело, час публікації, посилання на оригінал.
- Python-проксі на бекенді обходить CORS і віддає фронтенду розпарсений JSON.

### 3.6. «Про проєкт»
- Опис мети, чесний перелік того, що є реальним і чого немає, покрокова інструкція підключення токена alerts.in.ua, посилання на офіційні сервіси оповіщення.

## 4. Нефункціональні вимоги

- Без обов'язкової збірки (Node.js не використовується) — чисті HTML/CSS/JS (ES-модулі) + бібліотеки з CDN (Leaflet, Chart.js).
- Темна тема за замовчуванням, адаптивна верстка (mobile-first для стрічки подій і карти).
- Локальний запуск однією командою (`python server.py`) без встановлення додаткових пакетів.
- Токен API зберігається лише на сервері (`config.local.json`, у `.gitignore`, або змінна середовища) — фронтенд токена ніколи не бачить.
- Доступність: достатній контраст кольорів, читабельні розміри шрифту, keyboard-friendly навігація по вкладках.

## 5. Технічний стек

| Шар | Технологія |
|---|---|
| Розмітка/стилі | HTML5, CSS3 (Grid/Flexbox, CSS-змінні для теми) |
| Логіка | Vanilla JavaScript (ES-модулі), без фреймворків |
| Карта | Leaflet.js (CDN) + власний GeoJSON областей |
| Графіки | Chart.js (CDN) |
| Тривоги | Реальний API [alerts.in.ua](https://api.alerts.in.ua/v1/alerts/active.json), опитування раз на ~20 с через серверний проксі |
| Новини | Реальні RSS-стрічки, розпарсені бекендом |
| Бекенд | Python 3, лише стандартна бібліотека (`http.server`, `urllib`, `xml.etree`) — обслуговує статику й проксі `/api/rss`, `/api/alerts` |

## 6. Структура даних

### Подія (Event) — синтезується з відповіді alerts.in.ua
```json
{
  "id": "al_...",
  "timestamp": "ISO-8601 (реальний started_at з API, або момент відбою)",
  "oblastIso": "UA-63",
  "threatType": "air_raid | artillery_shelling | urban_fights | chemical | nuclear | alert_end",
  "description": "текст, зазначає джерело — alerts.in.ua"
}
```

### Новина (NewsItem)
```json
{
  "title": "...",
  "link": "...",
  "source": "назва джерела",
  "scope": "global | national | regional",
  "oblastIso": "UA-63 | null",
  "pubDate": "ISO-8601"
}
```

## 7. Інтеграція з alerts.in.ua

- Базовий endpoint: `GET https://api.alerts.in.ua/v1/alerts/active.json`, авторизація `Authorization: Bearer <token>`.
- Токен видається безкоштовно за заявкою на https://alerts.in.ua/api-request.
- `server.py` бере токен з `ALERTS_API_TOKEN` (env) або `config.local.json`, підставляє в запит, віддає фронтенду `{configured, reason, message, alerts}` — сам токен клієнту не передається.
- `js/alerts.js` опитує `/api/alerts` кожні ~20 с, зіставляє `location_oblast`/`location_title` з відповіді з нашим довідником областей (нормалізація назв), і на основі змін активного набору синтезує `alert_start`/`alert_end` події для решти застосунку.
- Якщо токен не налаштований або недійсний — сайт показує чесний банер "не налаштовано" з інструкцією, без підміни фейковими даними.

## 8. Обмеження поточної версії

- Немає офіційного джерела з координатами конкретних ударів — тільки статус тривоги по областях.
- Немає історичного архіву тривог від alerts.in.ua — статистика й журнал накопичуються лише з моменту запуску сервера.
- Новини залежать від доступності зовнішніх RSS-джерел (можливі тимчасові збої в окремих джерелах).
- Немає БД — стан тривог і накопичена історія живуть у пам'яті вкладки браузера (JS-стан), зникають при перезавантаженні сторінки.
