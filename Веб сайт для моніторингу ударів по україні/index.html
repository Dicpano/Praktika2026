Про проєкт

Навчальний сайт моніторингу повітряних тривог України в розрізі областей, разом з агрегацією новин глобальних, всеукраїнських та обласних медіа.

Звідки дані:

  • Тривоги — офіційний API alerts.in.ua (реальний стан «оголошено/відбій» по областях). Потребує безкоштовного токена — див. розділ нижче.
  • Новини — реальні публічні RSS-стрічки (список нижче).

Чого тут немає: офіційного API з координатами конкретних ударів (Шахед/ракета/КАБ) не існує публічно — такі дані поширюються лише неофіційно (моніторингові Telegram-канали), без гарантії точності, тому в проєкті їх свідомо немає. Це не заміна офіційного оповіщення: для рішень щодо безпеки орієнтуйтесь на сирени, застосунок «Повітряна тривога», офіційний Telegram-канал Повітряних Сил ЗСУ та вказівки ДСНС.

Як підключити реальні тривоги

  1. Подати заявку на токен на alerts.in.ua/api-request (поле «Галузь використання» → Other).
  2. Отримати токен на email.
  3. Скопіювати config.example.json → config.local.json і вставити токен у поле alerts_api_token (або задати змінну середовища ALERTS_API_TOKEN).
  4. Перезапустити python server.py.

Технічна реалізація

Чистий HTML/CSS/JavaScript (без збірки), карта на Leaflet.js, графіки на Chart.js, локальний Python-сервер (лише стандартна бібліотека) роздає статику й проксує RSS та alerts.in.ua. Повне технічне завдання — у файлі TZ.md у корені проєкту.
