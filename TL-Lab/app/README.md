# TL-Лабораторія 3.0

Навчальний застосунок до заняття 4.13 «Практичне використання репозиторіїв аналітичних моделей»
(НУОУ, кафедра інформаційно-аналітичних технологій, група 5202).

**Установка й запуск — лише через портативну версію:** `INSTALL.bat` у корені папки TL-Lab (один раз, з Інтернетом),
далі `TL-Lab.bat` або ярлик «TL-Лабораторія». Детально — посібник користувача (PDF) і `ПРОЧИТАЙ.txt`.

## Модулі

| # | Задача | Готова модель | Що адаптовано |
|---|---|---|---|
| 01 | Фото: БПЛА, бронетехніка, артилерія, вантажівка, замасковані позиції, немає цілі | ResNet18 (ImageNet) | новий шар fc + аугментація, Grad-CAM |
| 02 | Документи: донесення, повідомлення, довідка, наказ, рапорт, заявка | MiniLM-L12 multilingual | логістична регресія на ембеддингах |
| 03 | Звуки: Шахед, реактивний Шахед, вертоліт, літак, техніка, бензопила, сирена, фон | YAMNet (AudioSet) | логістична регресія на ембеддингах |
| 04 | Кластеризація 60 повідомлень (6 тем) | MiniLM + KMeans | готові ознаки, silhouette + метод «ліктя» |
| 05 | Тестові запитання (3 варіанти / правда-неправда), експорт Word і Moodle | Qwen3-0.6B | few-shot, RAG, LoRA |
| 06 | RL-агент у змінених умовах (фізика, вітер, шум датчиків) | PPO CartPole і Acrobot (rl-zoo) | донавчання + контроль забування |

## Архітектурні рішення

- **Двигун FastAPI + власний вебінтерфейс** (версія 3.0 замість Streamlit): сторінки перемикаються в браузері без
  перезавантаження, сервер лише віддає дані; прогрес задач надходить потоком подій (Server-Sent Events).
- **Фонові задачі** (`core/jobs.py`): навчання йде в пулі потоків сервера — перехід між сторінками їх не зупиняє;
  черга, прогрес, журнал, скасування.
- **Окремі процеси** для TensorFlow/YAMNet і Qwen: конфлікт бібліотек чи нестача пам'яті не закривають програму.
- **Продуктивність**: прогрів бібліотек у фоні після старту, кеш моделей у пам'яті, `OMP_WAIT_POLICY=PASSIVE`,
  PPO в один потік, Plotly/KaTeX підвантажуються локально.
- **Журнали**: `app/logs/server.log` (сервер, аварії з трасуванням), `app/logs/app.log`, `app/logs/qwen_worker.log`.

Навчальний макет. Не для бойового застосування. Лише відкриті, синтетичні або знеособлені дані.
