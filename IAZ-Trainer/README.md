# Штаб-аналітик — тренажер ІАЗ

Ігровий тренажер елементів інформаційно-аналітичного забезпечення у форматі «напиши селектор — відбери потрібне». На карті обстановки є донесення, цілі, сектори й теки. Гравець пише CSS-селектор, що відбирає саме ті об'єкти, які вимагає наказ.

## Як запустити

Відкрийте `index.html` у браузері. Сервер не потрібен. Прогрес зберігається в браузері.

## Зміст: 23 завдання, 5 етапів циклу ІАЗ

| Етап | Елементи ІАЗ | Синтаксис |
|---|---|---|
| I. Збір та облік | облік донесень, цілі, журнал обліку, смуга відповідальності | `тип`, `#id`, `A B` |
| II. Класифікація | види розвідки, PIR, вибірка під споживача, передача смуги | `.клас`, `тип.клас`, `A, B`, `*` |
| III. Оцінка достовірності | первинна обробка, адміралтейська система (A–F / 1–6), відсіювання дезінформації | `[attr]`, `[attr="v"]`, `:not()` |
| IV. Аналіз і кореляція | зведення, первинне й актуальне донесення, підтвердження з кількох джерел, cross-cueing, BDA, прогалини | `>`, `:first-child`, `:last-child`, `:only-child`, `+`, `~`, `:empty` |
| V. Узагальнення та доведення | категорії терміновості, захист від перевантаження, розвідувальний продукт (SALUTE) | комбіновані запити |

Відповідь зараховується, якщо вона відбирає рівно ті самі елементи, що й еталон, тому правильних записів може бути кілька.

## Структура

- `index.html` — розмітка інтерфейсу
- `css/style.css` — військовий стиль
- `js/levels.js` — завдання: наказ, еталонний селектор, довідка, доктрина, обстановка
- `js/game.js` — рушій гри: карта, журнал, приціл, перевірка, звання

Щоб додати завдання, допишіть об'єкт у `window.LEVELS` у `js/levels.js`.

Усі дані й ситуації вигадані та призначені лише для навчання.
