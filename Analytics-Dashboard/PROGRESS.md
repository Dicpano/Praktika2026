## 2. Ухвалені рішення

### Шрифти
- **Volja = «UAF Sans»** (підтвердив замовник). Volja використовується для всього інтерфейсу: заголовки, текст, таблиці, осі, tooltip.
- Підключення: `@font-face` у `css/fonts.css`; Regular 400 (woff2 + ttf), Black 900 (ttf).
- Стек завжди закінчується системним шрифтом, бо у Volja немає гліфів `% + ʼ`, а в Black ще й `- ( ) / « » №`.
- Для Chart.js: спершу `document.fonts.load()` з таймаутом 3 с, далі `Chart.defaults.font.family`, і `update()` уже створених графіків. Кольори беруться з CSS-токенів, при зміні теми застосовуються знову.
- Друкована довідка: Times New Roman 12–14 пт (п. 1.4.1 Порядку).
- Для офлайн-збірки шрифти треба вбудувати в CSS (base64), бо з `file://` шрифти можуть не завантажитися.

### Умовні знаки

- Рендер — milsymbol 2.x (SIDC 2525C), режим кольорів `Order140` за табл. 6.
- Позначки ураження за п. 2.2.12 малюються власним SVG-шаром. Там само: «?» для неперевірених даних (п. 2.2.15), смуга боєздатності AL, монохромний режим «ПТН» / подвійна лінія (п. 2.2.13).
- Місця уражень БпЛА, КР, БР і КАБ: знак «Вибух, підрив» (п. 6.12) → `OHVPE----------` з підписом БпЛА / КрР / БалР / КАБ. **Траєкторії не показуються.** Знаки засобів у польоті прибрано.
- Ланки за табл. 8: ОСУВ «XXXX» (K), ОТУ / корпус «XXX» (J), бригада «X» (H) тощо. Пункт управління позначається флагштоком (п. 6.1).
- Класи калібру за табл. 16: ствольна артилерія <120 / 120–160 / >160 мм; міномети <60 / 60–107 / >107; РСЗВ — «Град» середній, «Ураган»/«Смерч» великий.
- Скорочення джерел — повний перелік п. 2.2.15 (27 кодів).
- Лінія зіткнення (п. 6.2.1): синя дугова лінія — свої, червона — противник, дуги звернені до протилежної сторони.
- Противник, лінія і зони беруться з DeepStateMap, з атрибуцією та датою «станом на». Свої підрозділи вигадані з позначкою «(умовна)».

### Карта
- Розмір знака: 14 px на масштабі 5 → 42 px на 12 (CSS-змінна `--s`). Видимість задається класами `mz-N` / `zl-N`.
- Пороги видимості:

  | Об'єкт | З масштабу |
  |---|---|
  | ОСУВ / ОТУ | 5,5 |
  | бригади | 6,5 |
  | полки | 7 |
  | батальйони | 8 |
  | роти | 9,5 |
  | підписи | 8,5 |
  | противник: армії / корпуси | 5,5 |
  | противник: дивізії | 6,5 |
  | противник: бригади / полки | 7 |
  | противник: батальйони | 8 |

  На масштабі 5 знаки зникають.
- Потоки ОКП будуються ієрархічно по `parent_id` («підлеглий → старший»). Їх видимість — за тими самими порогами (ОТУ → ОСУВ з 5,5 … рота → батальйон з 9,5).
  - товщина ∝ √обсягу в межах ланки;
  - колір за часткою прострочених: < 5 % / 5–10 % / > 10 %;
  - стрілка показує напрям.

### Правила оформлення графіків (чекліст §10.6 ТЗ)
- **Одна вісь Y.** Дві величини різного масштабу показуються двома панелями (A2) або точковою діаграмою (C3); D2 — у % від нормативу.
- Вісь Y стовпчиків починається з нуля. Підписи осей мають одиниці виміру.
- Числа у форматі `uk-UA`. Час: `ГГ.ХХ ДД.ММ.РРРР`, київський (п. 2.1.1).
- Кольори:
  - лише з палітри модуля (брендбук), 5–6 категорій;
  - один зміст має один колір у всіх графіках;
  - червоний — лише для загрози, втрат і прострочення;
  - без 3D, кругових діаграм і градієнтів.
- Легенда показується лише для двох і більше рядів.
- Під кожним графіком — підпис джерела і «станом на».
- Відсутні значення — «немає відом.» (п. 2.3.6). У втратах значення 1–4 показуються як «<5».
- Кожен графік має tooltip з одиницею, `aria-label`, перемикач «Показати таблицю», CSV і PNG.
- Таблиці за п. 2.3:
  - нумераційний і тематичний заголовок;
  - перша графа «№ з/п»;
  - без порожніх клітинок.
